The Gateway That Learned to Say No

Degradation as a first-class contract

Part 1 answered how the ladder stays up. Part 2 answers the harder question — how the system stays honest while it's degraded. A semantically wrong answer, a silently duplicated retry, a prompt rollback that needs a redeploy: availability alone doesn't touch any of them. This is the layer of contracts, config-as-data and invariant validation that does.

“Availability is what keeps the door open. The contract is what keeps it honest.”

01 · The problem part 1 didn't solve

Success is not correctness

The ladder in Part 1 ensures a response always comes back. It says nothing about whether that response is right. During a Gemini degradation window, a well-formed but semantically wrong answer passed every tier as success — caught only because a downstream payroll validator rejected the number. Prompt edits required a redeploy; cost was attributed by provider-reported usage that silently lied across retries. And callers could ignore the tier entirely.

02 · The approach

Make degradation a contract

Every response carries tier, degraded and confidence as a discriminated union — the type system forbids ignoring them. Prompts and routing policies live in Redis and reload via pub/sub. Cost is computed from our own price table, not the provider's. A fourth orthogonal tier — invariant validation — runs after every "successful" call, because the ladder protects availability and invariants protect correctness.

Implementation

LlmResponse.ts · TypeScript / NestJS

export type LlmTier = 'retry' | 'rag' | 'floor';
export type Confidence = 'high' | 'medium' | 'low';

export type LlmResponse<T> =
  | { tier: 'retry'; degraded: false; confidence: 'high'; content: T;
      providerMeta: ProviderMeta; invariants: InvariantReport }
  | { tier: 'rag' | 'floor'; degraded: true; confidence: 'medium' | 'low'; content: T;
      providerMeta: ProviderMeta; invariants: InvariantReport };

/**
 * Callers cannot read `.content` on a degraded response without
 * explicitly acknowledging it. The type system refuses; the runtime
 * throws if they try to bypass it with `as any`.
 */
export function acceptDegraded<T>(res: LlmResponse<T>): T {
  if (res.degraded && !res.invariants.passed) {
    throw new DegradedInvariantViolation(res.invariants.violated);
  }
  if (res.degraded) {
    logger.warn('degraded_accept', {
      tier: res.tier, confidence: res.confidence,
      violations: res.invariants.violated,
    });
  }
  return res.content;
}

// Gateway side — invariant validation runs AFTER a Tier-1 success.
const raw = await this.dispatchPrimaryLLM(req, tenantContext);
const invariants = this.invariantEngine.check(raw, req.domainRules);

if (!invariants.passed) {
  // Tier 1 "succeeded" but violated a domain rule. Downgrade.
  return this.ruleEngine.extractHeuristicData(req.rawDocument, 'floor', invariants);
}

return { tier: 'retry', degraded: false, confidence: 'high', content: raw, providerMeta, invariants };
